# VocabMate

Private Telegram flashcard bot using SM-2 spaced repetition for daily vocabulary practice; create/import decks, quick mobile reviews, reminders, and progress tracking.

Spec: [`docs/blueprint.md`](docs/blueprint.md).

Built on [agnt-gm.ai](https://agnt-gm.ai). The whole bot is built and refined here as pull requests across successive build passes.
